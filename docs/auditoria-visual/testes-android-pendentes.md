## Preparação comum

- Usar build de desenvolvimento, conta de teste e dados sintéticos. Não usar dados pessoais ou executar exclusões reais. Módulos necessários devem estar habilitados no ambiente de teste, respeitando dependências.
- Registrar aparelho, Android/build, resolução, dimensões lógicas, escala de fonte e modo de navegação em cada execução. “Tela pequena” nesta matriz significa aproximadamente 320–360 dp de largura; não confundir pixels físicos com dp.
- Comparar fonte 1,0 com 1,3 e 2,0 (ou os níveis equivalentes nas configurações do aparelho). Não desabilitar `allowFontScaling` para simular aprovação.
- Restaurar fonte, tamanho de exibição e navegação ao terminar. Anexar apenas screenshots sem informações pessoais.
- Quando um caminho não estiver disponível, registrar **não executado / bloqueado**, com o motivo. Só alterar PENDENTE para aprovado/reprovado com execução real, evidência e data.
