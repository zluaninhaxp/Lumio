Add video and image assets for the app splash and intro screens here.

- Place video files (mp4) in this folder or subfolders.
- Place static images (png, jpg, webp) here.

Usage:
- Import videos in components using: `require('../../assets/media/your-video.mp4')`.
- Use `expo-av`'s `Video` component for playback.

Note: For Android, prefer H.264/AAC MP4 files for compatibility.
